# حفظني (Hafidni)

تطبيق ويب بالعربية (RTL) لمراجعة وحفظ الدروس. **هذه النسخة هي الهيكل فقط**: التنقل، الشاشات، طبقة البيانات المحلية، والمكوّنات. لا توجد فيها أي مواد أو دروس أو بطاقات أو أسئلة.

تقنيات: HTML + CSS + JavaScript عادي. بدون إطار عمل، بدون خادم خلفي، بدون تسجيل دخول حقيقي، بدون ذكاء اصطناعي أو دفع أو إشعارات أو PWA.

## كيف تشغّل التطبيق

التطبيق يقرأ `content.json` عبر `fetch`، لذلك **لا يعمل بالنقر المزدوج على index.html** (فتح الملف مباشرة عبر `file://` يمنع قراءة `content.json`، وسيظهر لك تنبيه بالعربية بذلك). شغّله عبر خادم محلي بسيط من مجلد المشروع:

```bash
python3 -m http.server 8000
```

ثم افتح في المتصفح: `http://localhost:8000/`

(بديل: `npx serve .`)

## كيف تضيف المحتوى لاحقاً في content.json

الشكل العام:

```json
{ "levels": [], "streams": [], "subjects": [], "lessons": [] }
```

- **levels / streams** (اختياري): قائمة `{ "id": "...", "title": "..." }`. إذا بقيتا فارغتين يستعمل التطبيق الخيارات الافتراضية الموجودة في `js/config.js`.
- **subjects**: `{ "id": "math", "title": "اسم المادة", "levelId": "bac1", "streamId": "physics" }`
  (`levelId` و`streamId` اختياريان.)
- **lessons**: كل درس مرتبط بمادة عبر `subjectId`:

```json
{
  "id": "lesson-1",
  "subjectId": "math",
  "title": "عنوان الدرس",
  "minutes": 15,
  "objectives": ["هدف 1", "هدف 2"],
  "intro": "نص المقدمة",
  "summary": "نص الخلاصة",
  "cards": [
    { "front": "السؤال أو المصطلح", "back": "الجواب أو التعريف" }
  ]
}
```

- **بطاقات الحفظ** توضع داخل الدرس في الحقل `cards` (كل بطاقة: `front` و`back`).
- النصوص تُعرض كنص عادي (لا يُفسَّر HTML)، لذلك لا تضع وسوم HTML فيها.
- المعرّفات (`id`) يجب أن تكون فريدة ولا تتغير بعد أن يبدأ المستخدمون في استعمالها، لأن التقدم المحفوظ يرتبط بها.

## أين تُحفظ البيانات؟

في `localStorage` تحت المفتاح `hafidni:v1` على جهاز المستخدم فقط: الاسم، المستوى، الشعبة، آخر درس، حالة البطاقات. كل قراءة وكتابة داخل `try/catch`، وإذا فشل الحفظ تظهر رسالة صريحة بالعربية. **لا يُحفظ البريد الإلكتروني ولا كلمة المرور إطلاقاً.**

## ما هو بنية فقط (غير مكتمل عمداً)

- **إنشاء الحساب**: يتحقق من المدخلات فقط ولا ينشئ أي حساب. زر Google معطّل "غير مفعّل بعد". "عندي حساب" يفتح نفس الشاشة لأنه لا يوجد تسجيل دخول.
- **الاختبارات (9)**: أنماط الاختبار ظاهرة لكنها معطّلة بلا أي منطق أسئلة. صفحة "سجل الاختبارات" فارغة.
- **الألعاب (10)**: الست كلها معطّلة "قريباً".
- **النقاط والأيام المتتالية والدروس المكتملة**: تُقرأ من التخزين وتبدأ من 0؛ لا يوجد بعد ما يزيدها. النقاط تظهر في الملف الشخصي فقط.
- **توصيات المراجعة وسجل الأنشطة**: صفحات بحالة فارغة فقط.
- **شاشة التحفيز (12)**: المسار موجود لكنها لا تُفتح تلقائياً؛ زر اختبارها مخفي في الإعدادات داخل "أدوات المطوّر (للتطوير فقط)".
- **المستوى والشعبة**: خياراتها ثابتة من `js/config.js` وكلها قابلة للاختيار (لأنها تفضيلات للمستخدم وليست محتوى دراسياً).
- **بطاقات الحفظ** وقائمة الدروس والبحث والتصفية: تعمل بمجرد وجود دروس وبطاقات في `content.json`، لكنها لم تُجرَّب بمحتوى حقيقي بعد.
